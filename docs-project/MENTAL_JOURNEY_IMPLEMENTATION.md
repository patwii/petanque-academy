## 🔄 Differences Between Resources

### Mental Journey (Beginners) vs Workshop (Advanced)

| Aspect | Mental Journey | Workshop |
|--------|----------------|----------|
| **Duration** | 2-3 hours | 3-4 hours |
| **Depth** | Introduction | Deep psychological work |
| **Audience** | Beginners | Elite players |
| **Focus** | Basic concepts & tools | Vulnerability-based learning |
| **Exercises** | Simple (3-breath reset, routines) | Advanced (Fear in a Hat, User Manual) |
| **Outcome** | Understanding & basic skills | Team psychological intelligence |

### Workshop vs Training Camp

| Aspect | Workshop | Training Camp |
|--------|----------|---------------|
| **Duration** | 3-4 hours | Full weekend |
| **Format** | Theory only | Theory + Practice + Competition |
| **Location** | Indoor room | Facility with pistes |
| **Group Size** | 6-8 players | 10-20 players |
| **Staff** | 1 facilitator | 4-6 staff members |
| **Outcome** | Mental insights | Integrated application |

---

## 🎓 Learning Pathway

**Recommended Progression:**

1. **Start:** Mental Journey (2-3h introduction)
2. **Deepen:** Workshop (3-4h advanced theory)
3. **Integrate:** Training Camp (weekend application)
4. **Practice:** Training Session (ongoing practice)
