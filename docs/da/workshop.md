# Workshop

## Fora for Elitespillere

Vores workshops er intime fora, hvor elitespillere deler erfaringer og åbner op om deres indre tanker om spillet, præstation og mentale udfordringer.

## Format

### Små Grupper
- **6-8 spillere** per workshop
- Omhyggeligt udvalgte grupper for optimal dynamik
- Trygt rum for ærlig diskussion

### Hybrid Tilgang
- **Første møde: Personligt (IRL)**
  - Opbyg tillid og forbindelse
  - Etabler gruppedynamik
  - Sæt intentioner og mål

- **Løbende sessioner: Online**
  - Regelmæssige check-ins
  - Fortsat deling og støtte
  - Fleksibel planlægning for travle spillere

## Hvad Du Kan Forvente

- Dybe diskussioner om mentale aspekter af spillet
- Deling af personlige erfaringer og udfordringer
- Peer-støtte og ansvarlighed
- Praktiske øvelser og teknikker
- Et fællesskab af spillere dedikeret til vækst
