# Erstellen Sie Ihren Trainingsplan

Ziele ohne Plan sind nur Wünsche. Dieser Leitfaden hilft Ihnen, Ihre Ziele in einen strukturierten Trainingsplan umzuwandeln, der tatsächlich funktioniert.

## Die 8 Phasen der selbstgesteuerten Entwicklung

### Phase 1: Setzen Sie Ihren Kompass (Ziele)
Sie haben bereits über SMART-Ziele gelernt. Ordnen Sie sie nun in einer Hierarchie:

1. **Langfristiges Ziel** (1-2 Jahre): Ihr Traum
2. **Jahresziel**: Das Ziel dieses Jahres
3. **Quartalsziele**: 3-Monats-Meilensteine
4. **Monatsziele**: Spezifische Schwerpunktbereiche
5. **Wochenziele**: Trainingsziele

### Phase 2: Bewerten Sie Ihre Ressourcen

Bevor Sie planen, bewerten Sie ehrlich, was Sie haben:

| Ressource | Zu stellende Fragen |
|----------|-----------------|
| **Zeit** | Wie viele Stunden pro Woche können Sie realistisch trainieren? |
| **Standort** | Haben Sie Zugang zu einer ordentlichen Piste? Wie ist die Oberflächenqualität? |
| **Ausrüstung** | Haben Sie geeignete Kugeln? Messwerkzeuge? Videofähigkeit? |
| **Wissen** | Was sind Ihre technischen Stärken und Schwächen? |
| **Körperliche Verfassung** | Irgendwelche Einschränkungen? Bereiche, die Arbeit benötigen? |

Seien Sie ehrlich. Ein realistischer Plan schlägt eine ehrgeizige Fantasie.

### Phase 3: Wählen Sie Ihre Übungen

Wählen Sie Übungen, die Ihre Ziele direkt unterstützen:

**Für Verbesserung des Legens:**
- Präzisionslegung zu markierten Zonen
- Distanzvariationsübungen
- Verschiedene Oberflächenpraxis

**Für Verbesserung des Schießens:**
- Schießleiter (progressive Distanzen)
- Hindernisschießen (erzwungener hoher Bogen)
- Bewegliches Zieltraining

**Für mentale Entwicklung:**
- Vor-Wurf-Routine-Praxis
- Visualisierungssitzungen
- Drucksimulation

**Balancieren Sie Ihr Programm:**
- Technische Arbeit (Legen, Schießen)
- Mentaltraining (Achtsamkeit, Visualisierung)
- Körperliche Konditionierung (Balance, Flexibilität)
- Spielpraxis (Anwendung von Fähigkeiten)

### Phase 4: Erstellen Sie Ihren Zeitplan

Erstellen Sie einen realistischen Wochenplan:

| Tag | Morgen | Nachmittag | Abend | Fokus |
|-----|---------|-----------|---------|-------|
| Mo | - | Technisch: Legen | Leichte Mobilität | Präzision |
| Di | - | Technisch: Schießen | - | Kraft/Genauigkeit |
| Mi | - | Mentaltraining | - | Achtsamkeit |
| Do | - | Gemischt: Spielszenarien | Leichte Mobilität | Anwendung |
| Fr | - | Technisch: Schwäche | - | Verbesserung |
| Sa | Spielpraxis oder Wettkampf | - | - | Leistung |
| So | Ruhe | Wöchentliche Überprüfung | Planung | Erholung |

**Schlüsselprinzipien:**
- Priorisieren Sie Mentaltraining (es wird oft vernachlässigt)
- Schließen Sie Ruhetage ein
- Balancieren Sie verschiedene Fähigkeiten
- Lassen Sie Flexibilität für das Leben

### Phase 5: Bereiten Sie sich auf Hindernisse vor

Dinge werden schief gehen. Planen Sie dafür.

| Risiko | Wahrscheinlichkeit | Auswirkung | Backup-Plan |
|------|------------|--------|-------------|
| Zeitmangel | Hoch | Mittel | Haben Sie eine "Minimalsitzung" bereit (20 Min) |
| Schlechtes Wetter | Mittel | Mittel | Indoor-Visualisierung, Videostudie |
| Niedrige Motivation | Hoch | Mittel | Zurück zum "Warum", kleinere Ziele, Pause machen |
| Leichte Verletzung | Mittel | Hoch | Fokus auf Mentaltraining, nicht betroffene Fähigkeiten |
| Kein Trainingspartner | Mittel | Niedrig | Solo-Übungen, Video-Selbstanalyse |

### Phase 6: Verfolgen Sie Ihren Fortschritt

Was gemessen wird, wird verwaltet.

**Führen Sie ein Trainingstagebuch:**
- Datum und Dauer
- Abgeschlossene Übungen
- Punkte/Ergebnisse
- Wie Sie sich fühlten (Energie, Fokus, Flow)
- Technische Notizen
- Wetter/Bedingungen

**Wöchentliche Überprüfungsfragen:**
- Habe ich meine geplanten Sitzungen abgeschlossen?
- Welche Punkte habe ich erreicht?
- Was fühlte sich gut an? Was war schwierig?
- Irgendwelche Flow-Erfahrungen?
- Was sollte ich anpassen?

### Phase 7: Bleiben Sie motiviert

Motivation schwankt. Bauen Sie Systeme auf, um sie aufrechtzuerhalten:

**Interne Motivation:**
- Verbinden Sie sich mit Ihrem "Warum"
- Feiern Sie kleine Siege
- Bemerken Sie Verbesserung im Laufe der Zeit
- Finden Sie Freude am Prozess

**Externe Unterstützung:**
- Trainingspartner (auch gelegentlich)
- Teilen Sie Ziele mit jemandem
- Treten Sie Online-Communities bei
- Verfolgen Sie Serien und Konsistenz

**Wenn die Motivation sinkt:**
- Machen Sie eine Minimalsitzung (etwas schlägt nichts)
- Ändern Sie Ihre Umgebung
- Überprüfen Sie Ihren Fortschritt
- Erinnern Sie sich an vergangene Erfolge
- Nehmen Sie eine geplante Pause, wenn nötig

### Phase 8: Überprüfen und anpassen

Ihr Plan sollte sich entwickeln:

**Wöchentlich:** Schnelle Überprüfung, kleinere Anpassungen
**Monatlich:** Fortschritt zu monatlichen Zielen bewerten, Fokus anpassen
**Vierteljährlich:** Große Überprüfung, Ziele für nächstes Quartal setzen
**Jährlich:** Vollständige Bewertung, neuer Jahresplan

**Fragen zur Überprüfung:**
- Mache ich Fortschritte zu meinen Zielen?
- Ist mein Training effektiv?
- Brauche ich andere Übungen?
- Sind meine Ziele noch relevant?
- Was habe ich gelernt?

## Beispiel 8-Wochen-Plan

**Ziel:** Schießgenauigkeit um 15% verbessern

| Woche | Fokus | Schlüsselsitzungen |
|------|-------|--------------|
| 1 | Baseline | Aktuelles Niveau testen, Videoanalyse |
| 2 | Technik | Schlüsselproblem identifizieren und bearbeiten |
| 3 | Wiederholung | Hochvolumen-Schießpraxis |
| 4 | Test | Halbzeitbewertung, anpassen |
| 5 | Variation | Verschiedene Distanzen und Winkel |
| 6 | Druck | Konsequenzen zu Übungen hinzufügen |
| 7 | Integration | Spielähnliche Szenarien |
| 8 | Abschlusstest | Verbesserung messen |

## Kernaussage

> Planen Sie Ihre Arbeit, dann arbeiten Sie Ihren Plan. Aber seien Sie bereit, sich anzupassen.

Der beste Plan ist einer, den Sie tatsächlich befolgen werden. Beginnen Sie einfach, bleiben Sie konsistent und passen Sie an, während Sie lernen.
