# Workshop

## Forum for Elitespillere

Våre workshops er intime forum hvor elitespillere deler erfaringer og åpner sine indre tanker om spillet, prestasjon og mentale utfordringer.

## Format

### Små Grupper
- **6-8 spillere** per workshop
- Nøye utvalgte grupper for optimal dynamikk
- Trygt rom for ærlig diskusjon

### Hybrid Tilnærming
- **Første møte: Personlig (IRL)**
  - Bygge tillit og forbindelse
  - Etablere gruppedynamikk
  - Sette intensjoner og mål

- **Pågående økter: Online**
  - Regelmessige sjekk-ins
  - Fortsatt deling og støtte
  - Fleksibel planlegging for travle spillere

## Hva Du Kan Forvente

- Dype diskusjoner om mentale aspekter ved spillet
- Deling av personlige erfaringer og utfordringer
- Peer-støtte og ansvar
- Praktiske øvelser og teknikker
- Et fellesskap av spillere dedikert til vekst
