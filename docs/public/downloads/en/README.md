## How to Use These Materials

### Digital-First Approach (Recommended)

**Share links directly:**
- Email participants the links to materials on carreau.app
- Create QR codes for in-person sessions
- Use screen sharing for remote sessions
- Participants can bookmark on their devices

**Benefits:**
- Always up-to-date content
- Accessible on any device
- No printing costs
- Environmentally friendly

## Generating Updated Files

If you modify the markdown files and want to regenerate PDFs/PPTX:

```bash
python3 scripts/python/generate_downloads.py
```

This will regenerate all PDF and PPTX files from the markdown sources.
