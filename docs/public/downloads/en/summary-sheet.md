# Mental Game Quick Reference

**Pétanque Academy - One-Page Summary**

## The Zone / Flow State

**Two Modes of Mind:**

| Planning Mode | Execution Mode |
|---------------|----------------|
| Analyze terrain | Trust your body |
| Choose strategy | Don't think |
| Assess risks | Present moment |
| Make decisions | Automatic execution |

**The Switch:** Plan before, flow during

---

## Inner Critic vs Inner Coach

| Inner Critic ❌ | Inner Coach ✅ |
|----------------|---------------|
| "That was terrible!" | "What can I learn?" |
| "You always mess up" | "Next shot, fresh start" |
| "Everyone's watching you fail" | "I've done this before" |
| "You're not good enough" | "Trust the process" |

**Reframe:** Pause → Reframe → Reset → Refocus

---

## 3-Breath Reset

**Use after mistakes or pressure:**

1. **Breath 1:** Notice tension (where?)
2. **Breath 2:** Release tension (let go)
3. **Breath 3:** Refocus (this shot, now)

---

## Pre-Shot Routine

**Same routine, every shot:**

1. **Visualize** - See the shot
2. **Breathe** - One deep breath
3. **Anchor** - Touch boule, feel weight
4. **Execute** - Trust and throw

---

## Mistake Recovery Protocol

**After a bad shot:**

1. **Acknowledge** - "Didn't go as planned"
2. **Release** - Physical reset (shake it off)
3. **Refocus** - "Next shot is new"
4. **Execute** - Trust your routine

## Key Principles

1. **Flow is accessible** - You can learn to enter it consistently
2. **Your inner voice matters** - Coach yourself, don't criticize
3. **Simple tools work** - 3 breaths, a routine, a reset
4. **Practice is key** - Mental skills need training like technical skills
